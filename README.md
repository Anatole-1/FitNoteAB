# FitNote

Petite app de suivi de musculation (exercice, séries poids × reps, historique, progression).
Fonctionne hors ligne une fois installée sur l'écran d'accueil de l'iPhone.

## Mise en ligne sur GitHub Pages
1. Crée un dépôt public sur github.com (ex. `fitnote`).
2. Dépose tous les fichiers de ce dossier à la racine du dépôt (Add file → Upload files).
3. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
4. Après ~1 min, l'app est à `https://<ton-pseudo>.github.io/fitnote/`.
5. Sur l'iPhone, ouvre cette adresse dans Safari → Partager → « Sur l'écran d'accueil ».

Les données restent sur le téléphone (localStorage). Pense à exporter une sauvegarde de temps en temps (Réglages → Exporter).
